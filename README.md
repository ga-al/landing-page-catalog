# Каталог лендингов

Демонстрационный каталог лендингов: карточки кейсов, фильтры по нише, сроку и бюджету, сортировка и страница каждого кейса. Проекты и цены вымышленные, превью взяты с Unsplash.

## Стек

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Возможности

- Фильтры и сортировка без запросов к серверу
- Панель фильтров: на широком экране встроена в страницу, на узком открывается диалогом
- Скелетоны при смене выборки и пустое состояние со сбросом фильтров
- Учёт `prefers-reduced-motion`

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
npm start
```

## Структура

- `app/page.tsx` — страница каталога
- `app/cases/[id]/page.tsx` — страница кейса
- `app/_components` — каталог, фильтр, карточка и список
- `app/_lib/data.ts` — кейсы
- `app/_lib/filters.ts` — состояние фильтров и отбор карточек

Порядок массива `cases` считается порядком «от новых к старым»: сортировка «новее» его сохраняет, «дешевле» сортирует по полю `priceFrom`.
